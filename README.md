# RIGADIEL — Local, Independent AI

**On-device training and inference. No cloud, no API keys.**

RIGADIEL is Richard Felipe Urbina's own local AI, built into RIGCOM and RIGFORGE. It trains and runs on the device itself.

## What it does

- On-device training and inference (brain, cortex, embedded/mini models)
- Tokenizer, reasoning, graph and session ring
- Voice (voz_rosenberg)
- Built into RIGFORGE's Live Cards (Cartas Vivas): it generates an APK icon from a text instruction and applies it — tested live, a "Phoenix" icon as a 192 x 192 PNG from an instruction in Spanish

## Part of RIGCOM

RIGADIEL is product 12 of the RIGCOM ecosystem: 596 source files verified one by one with SHA-256, about 333,000 lines of C, 12,524 prototypes, 15 of 15 tests passed, 0 external dependencies in the core.
